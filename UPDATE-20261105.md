# Update 2026-11-05 — 20261105-25

The authoritative source was recovered from the workspace used by the My-bible-plan chat, then synchronized into this Git checkout because GitHub's main branch was older than the deployed application.

New setup screens include a positive book picker, a separate exclusion picker, group selection toggles in both lists, and an Advanced drag-and-drop order dialog. Explicit custom order takes precedence over parallel testament mode and includes Psalms in the chosen position. Selecting sequential/parallel mode restores default order.

New journeys reserve min(7, requestedDays ~/ 10) days inside the chosen duration. A 100-day choice produces 93 reading days and ends on start + 92. Existing serialized journeys preserve their previous duration. The reserve allowance remains available for the existing delay controls.

Arabic verse references display their chapter and verse from right to left using an isolated numeric run; English keeps chapter:verse.

Primary Hosting site: mybibleplan. Backup remains a separate stable snapshot. No Functions deployment or billing changes are needed.
